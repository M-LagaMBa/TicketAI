---
name: dev-debug
description: Investiga a causa raiz de um bug reportado, sem aplicar correção. Use quando o pedido for para investigar, diagnosticar ou entender por que algo está falhando.
---

1. Reproduzir o erro a partir do relato recebido.
2. Isolar a causa raiz, não só o sintoma.
3. Documentar os passos de reprodução.
4. Registrar hipóteses testadas e descartadas, não só a conclusão final.
5. Não alterar código de produção nesta etapa.
6. Ao final, entregar:
   - Relatório de causa raiz.
   - Passos de reprodução.
   - Sugestão de correção, sem aplicar.
