---
name: dev-correcao
description: Aplica a correção de um bug com base em um diagnóstico já feito. Use quando o pedido for para corrigir, aplicar fix ou resolver algo já diagnosticado.
---

1. Seguir o diagnóstico recebido; se discordar dele, justificar antes de agir diferente.
2. Corrigir apenas o necessário; evitar refatorações não solicitadas.
3. Validar que a correção não quebra outros pontos do sistema.
4. Adicionar teste de regressão sempre que possível.
5. Ao final, entregar:
   - Patch aplicado.
   - Explicação da correção.
   - O que foi testado para validar.
