---
name: dev-implementacao
description: Implementa uma funcionalidade ou correção do zero ou sobre código existente do projeto Cilia. Use quando o pedido for para desenvolver, criar ou implementar algo.
---

1. Ler a especificação ou o ticket recebido antes de codar.
2. Seguir os padrões e convenções já usados no projeto (nomenclatura, estrutura de pastas, estilo de código).
3. Implementar apenas o escopo pedido; não adicionar features extras.
4. Comentar decisões que não sejam óbvias no código.
5. Escrever testes básicos junto com a implementação, quando aplicável.
6. Ao final, entregar:
   - Resumo do que foi implementado.
   - Pontos de atenção para quem for revisar (trade-offs, partes sensíveis, dependências).
